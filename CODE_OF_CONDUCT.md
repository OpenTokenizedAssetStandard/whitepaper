# Code of Conduct

The **Open Tokenized Asset Standard (OTAS)** is a lab under **LF Decentralized Trust (LFDT)** and follows the LF Decentralized Trust Code of Conduct. Everyone who takes part, including contributors, maintainers, reviewers, and community members, is expected to uphold it.

📜 **[Read the LF Decentralized Trust Code of Conduct](https://www.lfdecentralizedtrust.org/code-of-conduct)**

In short: treat each other with respect, professionalism, and fairness; communicate constructively; welcome newcomers and assume good faith; and never harass, bully, or discriminate. The full [Code of Conduct](https://www.lfdecentralizedtrust.org/code-of-conduct) contains the complete text, along with details on how to report an incident.

---

*By participating in this project, you agree to abide by this Code of Conduct.*
